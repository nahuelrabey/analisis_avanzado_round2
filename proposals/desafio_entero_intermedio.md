# Transcripción de Desafío: Entero Intermedio

## Enunciado
Demostrar que, usando el Principio de Arquímedes, para todo $x \in \mathbb{R}$ existe $n \in \mathbb{Z}$ tal que:
$$ x < n \le x + 1 $$
