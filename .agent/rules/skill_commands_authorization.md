# Autorización Directa para Comandos de Skills

La invocación explícita por parte del usuario de cualquier comando de skill (por ejemplo, `/apunte`, `/ejemplo`, `/desafio`) cuenta como **autorización explícita** para crear, modificar e implementar directamente el contenido en los archivos del repositorio requeridos por dicha skill (como `apuntes-typst/apuntes.typ`, `apuntes-typst/ejemplos.typ`, `apuntes-typst/desafios.typ`), sin requerir confirmaciones adicionales ni pedir la palabra clave "implementá".
